# Brass & Ballast

A steampunk skyship twin-stick shooter. You captain a brass-and-canvas airship against the
Iron Syndicate's armada: dodge smog-choked flak, out-gun gunboats and zeppelin carriers, and
bring down five iron leviathans in a roguelite run that builds your ship as you fly it.

It is an installable, fully offline Progressive Web App written in vanilla JavaScript. There are
no dependencies, no build step and no network assets. Every sprite, sound, song and background
is generated by code when the game runs.

## Playing

### Controls

| Action | Keyboard + mouse | Gamepad | Touch |
|---|---|---|---|
| Move | WASD | Left stick / D-pad | Floating stick, left half of screen |
| Aim | Mouse (arrow keys also aim) | Right stick | Floating stick, right half of screen |
| Fire | Hold left mouse button (arrows fire while held; auto-fire in settings) | Right stick deflected, or RT | Right stick deflected |
| Boost (dash) | Space or Shift | A, LB or LT | BOOST button |
| Ballast bomb | Right mouse, E or Q | B or RB | BOMB button |
| Pause | Esc or P | Start | Pause button, top-left |
| Menus | Arrows or WASD, Enter, Esc / Backspace | D-pad or left stick, A, B, LB / RB tabs | Tap |

A second gamepad can press Start during a run to drop in as Player 2 (local co-op). XP is
shared; each living player picks their own upgrade card on level-up.

### Modes

- **The Grand Voyage**: the campaign. Five stages, each ending in a boss.
- **Endless Gale**: waves that never stop, with a boss every fifth wave and a new biome after
  each boss.
- **Daily Squall**: one date-seeded run per day, with two random modifiers. One local best
  per day.
- **Gauntlet of Iron**: all five bosses back to back, with refits in between. Unlocked after
  your first campaign win.

### Features

- Twin-stick airship handling with momentum, boosts, ballast bombs and a steam gauge.
- Primary cannons and auxiliary weapon systems that evolve into legendary forms.
- Roguelite level-ups offering upgrade cards, plus a persistent Workshop that buys permanent
  upgrades with cogs earned in every run.
- Five biomes with their own weather and skies, and five boss fights with telegraphed attacks.
- Codex, achievements and per-mode highscores.
- Juicy combat feedback (screen shake, hit-stop, smoke and sparks), with accessibility options
  for shake, flashing and damage numbers.
- Installable and offline. Install from the browser menu or the title screen; updates arrive
  as a "new rigging available" prompt.

## Running locally

From this folder:

```sh
node tools/serve.mjs            # http://127.0.0.1:8080
node tools/serve.mjs 9000       # or pick a port
```

The dev server sends `Cache-Control: no-store`, so edits show on reload. Service workers are
not registered on `localhost` or `127.0.0.1` by default, which keeps stale caches out of your
way while developing. Add `?sw=1` to a URL to test the service worker locally, or `?nosw=1`
to make sure it stays off.

Useful URL flags (see `docs/DESIGN.md` §10): `debug=1`, `autostart=1`, `autopilot=1`,
`mode=`, `hull=`, `weapon=`, `stage=N`, `boss=<id>`, `seed=N`, `god=1`, `mute=1`.

## Testing

```sh
node tests/smoke.cjs --help             # headless Chromium smoke run, prints a JSON report
node tests/pwa-check.cjs                # service worker install, precache and offline reload
node tests/input-check.cjs              # keyboard, mouse, gamepad and touch input harness
eslint js sw.js precache-manifest.js    # lint (flat config in eslint.config.mjs)
```

The Playwright-based checks use a globally installed `playwright` package.

## Architecture

- `index.html` loads `js/main.js`, which boots the engine, the UI and the audio.
- `js/core/` holds math, seeded RNG, the event bus and save storage.
- `js/game/` is the simulation: players, enemies, projectiles, pickups, director and AI.
- `js/content/` is data-driven content: hulls, weapons, enemies, bosses, upgrades, stages and
  modes. Adding content means adding a file, not touching the engine.
- `js/gfx/` draws everything with Canvas 2D: procedural sprites, particles, backgrounds and
  weather. `js/audio/` synthesizes all sound and music with WebAudio.
- `js/input/` unifies keyboard, mouse, gamepad and touch. `js/ui/` is the DOM interface.
- `js/pwa.js` and `sw.js` make the game installable and offline.

The full design, including the contracts between modules, lives in `docs/DESIGN.md`. The engine
API reference is `docs/ENGINE.md`.

## Deploying

The game is a static folder with no build step.

1. Regenerate the precache list. Run this after every change to a shipped file, or players keep
   the old cached version:

   ```sh
   node tools/gen-precache.mjs
   ```

   It writes `precache-manifest.js` with a version hash of every file under `index.html`,
   `manifest.webmanifest`, `css/`, `js/` and `icons/`.
2. Upload the folder to any static host. Serve it over HTTPS, because service workers require a
   secure context (localhost is the one exception).

Do not deploy `tests/`, `tools/` or `docs/`; they are not precached, but they are not needed to
play either.
