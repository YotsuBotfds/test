# BRASS & BALLAST — Design & Architecture Bible

> A steampunk skyship twin-stick shooter. You captain a brass-and-canvas airship against the
> Iron Syndicate's armada. Installable PWA, fully offline, zero dependencies, every pixel and
> every sound generated by code at runtime.

This document is the **single source of truth** for every work package (WP). Read §0, the
sections your WP touches, and your WP entry in §12. When the doc and a stub disagree, the doc
wins — except where real (non-stub) code already exists, in which case match the code.

---

## 0. Rules for every agent

1. **Ownership.** You own only the files listed for your WP in §12. Never edit anyone else's
   files. If you need something from another module that is missing, work around it inside your
   own files and list the request under **Integration notes** in your final report.
2. **No git state changes.** No `git add/commit/checkout/stash/reset`. Read-only git is fine.
3. **Tech.** Vanilla ES2022 modules, no bundler, no runtime npm deps, no network assets (no web
   fonts, CDNs, images, audio files). All art is drawn with Canvas 2D; all audio is synthesized
   with WebAudio. Relative imports with explicit `.js`.
4. **Style.** 2-space indent, single quotes, semicolons, ~100 col, `const`/`let`, `===`. JSDoc on
   exported APIs. Comments: sparse, explain *why*.
5. **Perf.** 60 fps on a mid phone. No allocations in per-entity hot loops where avoidable. Never
   use `ctx.filter` or `shadowBlur` per frame per entity — bake glows into sprites. Use
   `globalCompositeOperation = 'lighter'` for additive light.
6. **Robustness.** Your module must not throw if a collaborator's module is still a stub. Guard
   optional calls (`fn?.()`), check `Sprites.has()` where a fallback matters.
7. **Verify.** Run the smoke harness (§10) and look at your screenshots. Zero console errors
   attributable to your files is the bar. Files you don't own may be mid-construction by another
   agent — ignore errors that originate there.
8. **Report.** Final message: files written, what works, what's verified (with how), known
   gaps, integration notes for other WPs.

## 1. Vision & pillars

- **Feel first.** Floaty-but-responsive airship handling, punchy cannons, screen shake,
  hit-stop, smoke, sparks, flying cogs. Every shot should feel like a cannon.
- **Readable chaos.** Enemy fire is always hot orange/red/magenta with a bright core and a dark
  rim, drawn above everything else. Player fire is brass/gold/aether-cyan.
- **Build-craft.** Roguelite runs: XP level-ups offer 3 cards (passives, auxiliary weapon
  systems, primary calibrations, evolutions). Persistent Workshop upgrades between runs.
- **Steampunk all the way down.** Brass, rivets, gauges, canvas envelopes, ship's bells, steam
  whistles, anvil-clank percussion, accordion and brass-band music.
- **Plays everywhere.** Keyboard+mouse, gamepad (incl. 2-player local co-op), touch (dual
  floating sticks). Installable, offline, landscape-friendly, portrait-tolerant.

## 2. Game design

### 2.1 Core loop
Title → Mode select → Hangar (pick hull + primary cannon) → **Run**:
- A **stage** = 5 **waves** (~35–45 s each) → **boss** → **Refit** (pick 1 of 3 rare+ cards, heal
  40%) → transition to next stage/biome.
- Enemies drop **Aether shards** (XP) and **Cogs** (currency). XP fills the Aether gauge; each
  level-up pauses and offers 3 upgrade cards.
- Death → Results; cogs are banked to the Workshop for permanent upgrades & unlocks.
- Campaign = 5 stages. Victory after the stage-5 boss.

### 2.2 Modes (`js/content/modes.js`)
| id | name | summary |
|---|---|---|
| `campaign` | The Grand Voyage | 5 stages, 5 bosses. |
| `endless` | Endless Gale | Infinite generated waves, boss every 5th wave (cycling, scaling), biome changes after each boss. |
| `daily` | Daily Squall | Date-seeded: stage order shuffled (always 5), 2 random **modifiers**; one local best per day. |
| `bossRush` | Gauntlet of Iron | All 5 bosses back-to-back with refits between. Unlocked after first campaign win. |

**Modifiers** (`MODIFIERS`), each `{id, name, desc, apply(mods)}` mutating `run.mods`:
`gale` (strong wind), `glassCannon` (playerDmg ×2, playerDmgTaken ×2), `swarm` (spawnRate ×1.5,
enemyHp ×0.6), `volatile` (all enemies explode on death), `fog` (reduced visibility vignette),
`ironclad` (enemyHp ×1.6, xp ×1.5), `speedDemon` (enemySpeed ×1.25, enemy bullet speed ×1.25),
`richSkies` (cogs ×2, enemyDmg ×1.2), `lowBallast` (start 0 bombs, bomb drops ×3),
`eliteHunt` (eliteChance +0.25).

`run.mods` defaults: `{ enemyHp:1, enemyDmg:1, enemySpeed:1, enemyBulletSpeed:1, playerDmg:1,
playerDmgTaken:1, spawnRate:1, eliteChance:0, xp:1, cogs:1, wind:0, volatileAll:false, fog:false,
bombDrops:1, startBombs:null }`.

### 2.3 Controls
| action | keyboard + mouse | gamepad (standard) | touch |
|---|---|---|---|
| move | WASD | left stick / d-pad | floating stick, left half |
| aim | mouse, or arrow keys | right stick | floating stick, right half |
| fire | LMB hold (or auto-fire setting), arrows fire while held | right stick deflection > 0.35, or RT | right stick deflected > 0.25 |
| boost (dash) | Space / Shift | A / LB / LT | BOOST button |
| ballast bomb | RMB / E / Q | B / RB | BOMB button |
| pause | Esc / P | Start | ❚❚ button top-left |
| menus | arrows/WASD, Enter, Esc/Backspace | d-pad/LS, A, B, LB/RB tabs | tap |

Second gamepad pressing Start during a run spawns **Player 2** (drop-in co-op). Team XP; each
living player picks their own card on level-up (sequentially).

### 2.4 The player airship
- Physics: acceleration-based with exponential drag; `speed` ≈ 240 u/s, `accel` ≈ 1500.
  Hull sprite rotates smoothly toward travel direction (turn rate ~4 rad/s); turret rotates
  instantly to aim. Slight bob/roll wobble for life.
- **Hull** (HP). Contact & bullets damage it. `armor` subtracts flat damage (min 1).
  I-frames 0.6 s after a hit, with blink.
- **Steam** (0..steamMax, regen/s). Spent by **Boost**: dash impulse ~650 u/s for 0.18 s,
  i-frames 0.35 s, costs `boostCost` (default 30 of 100), 0.25 s cooldown. Steam-puff trail.
- **Ballast bombs** (`bombsMax`, start full). Drop → fuse 0.6 s → explosion radius 170,
  damage 60×`damage`, clears enemy bullets within radius, big shake. Bomb pickups refill.
- Low hull (<25%): smoke trail, alarm sfx every 2 s, red vignette pulse.
- Combo: kills within 2.5 s of each other chain; multiplier = 1 + 0.1 × chain (max ×5).
  Taking damage resets. Score per kill = enemy.score × multiplier.

## 4. Engine architecture (WP1 implements; everyone consumes)

### 4.1 Coordinates & time
- World units ≈ CSS px at zoom 1. **Infinite open sky** (no arena bounds). Origin is where the
  run starts. +x right, +y down. Angles in radians, 0 = +x, positive = clockwise on screen.
- **Sprites face +x** at angle 0.
- `renderer.camera.zoom` is area-preserving: `clamp(sqrt(cssW·cssH / (1280·720)), 0.5, 2)` ×
  gameplay zoom multiplier — the visible world area is roughly constant on any screen.
- Variable timestep: `dt = min(frameDelta, 1/30) × timeScale`. `world.time` = simulated
  seconds. Hit-stop freezes simulation (not rendering) for a few frames; slow-mo scales dt.

### 4.2 Frame order (game.js)
```
input.update(dt)
ui.update(dt)                               // menu nav when a screen is open
if simulating: world.update(dt)             // players, aux, enemies, projectiles, pickups, hazards,
                                            // collisions, director, fx/particles
background.update(dt), weather.update(dt, renderer, world), hud.update(dt)
render:
  background.drawBack(ctx, renderer)        // screen space: sky, ground, low clouds (parallax)
  [world transform]
```

### 4.4 Entities
**Enemy** (created by `spawnEnemy`; defs fill behavior):
```js
{ id, type, def, team:'enemy', x, y, vx, vy, r, angle, scale:1, alpha:1, alt:1,
  hp, maxHp, t /*age*/, alive:true, dead:false, isBoss, parent, wave,
  elite /*null|'armored'|'overclocked'|'volatile'*/, speedMult, fireRateMult, dmgMult,
  contactDamage, mass, kbx, kby, flash, burn:{dps,t}, slow:{amt,t},
  invuln:false, untargetable:false, state:'', timer:0, data:{} }
```
Core per-frame for each enemy: `t += dt` → `def.update(e, dt, world)` → unless
`def.manualMove`, integrate `x += (vx·(1−slow) + kbx)·dt` → decay knockback/flash → burn ticks
→ soft separation (unless `def.noSeparation`) → contact damage to players (unless
`def.noContact`) → non-boss enemies farther than 2600 from every player are recycled to a
fresh offscreen point.

**Enemy def** (`ENEMIES[id]`, also used for inline part/minion defs):
```js
{ id, name, hp, r, speed, contactDamage, mass:1, xp, cogs /*expected cogs, may be fractional*/,
  score, sprite, scale:1, alt:1, manualMove:false, noContact:false, noSeparation:false,
  init(e, world), update(e, dt, world), draw?(ctx, e, world),
  onDeath?(e, world, info), onHit?(e, amount, info, world) }
```
Default draw: `Sprites.draw(ctx, def.sprite, x, y, angle, scale, alpha)` + white flash overlay
via `Sprites.drawFlash` while `e.flash > 0`; elite: `Sprites.drawOutline` gold beneath.

**Boss def** (`BOSSES[id]`) = enemy def plus `{ boss:true, title, music:'boss'|'finalBoss',
stage, intro?(boss, world) }`. Parts are spawned with `world.spawnEnemy(partDef, x, y,
{parent: boss})`. Parts with `def.shareDamage` forward damage to the parent. Boss HP shown =
`boss.hp / boss.maxHp` (keep parent hp authoritative).

**Player** (`js/game/player.js`):

### 4.5 Projectiles (`world.fire(opts)`, engine in `js/game/projectiles.js`)
```js
{ team:'player'|'enemy', kind, sprite?, x, y, angle, speed, vx?, vy?, r:5, damage:10,
  life:2, range?, pierce:0, bounce:0, drag:0, accel:0, maxSpeed?, homing:0 /*rad/s*/,
  homingRange:400, lob:null /*{tx,ty,time,height}: no collision until landing → onLand/explode*/,
  explode:null /*{radius, damage, falloff}*/, burn:null, slow:null, knockback:60,
  crit:false, scale:1, spin:0, trail:null /*'smoke'|'spark'|'aether'|'steam'*/, glow:null,

```
Default sprite = `(team==='player' ? 'pb_' : 'eb_') + kind`. Player shots roll crits using
`owner.stats.crit` unless `crit` given. Player projectile damage is *not* auto-multiplied:
weapons compute final damage using stats. Enemy projectile damage IS auto-multiplied by the
firing enemy's `dmgMult` when `owner` is an enemy (or pass `dmgMult` explicitly).
Bounce reflects toward the nearest other enemy within 300. Pierce keeps a per-projectile hit set.

  `#e39a62 #b4643c #6e3a1f`, iron `#9aa3ad #5b626b #353a41 #1f2328`, wood `#a0703e #6e4723
  #3f2812`, canvas `#f3e8c9 #d8c69c #9e8a5e`, oxblood `#8c2f2b`, navy `#2e4a6b`, aether
  `#7ff3ff #33c9c0`, syndicate `#4b4f58 #2a2c31 #c0392b #ff7a2f`, steam `#f4f1ea`, enemy fire
  `#ff4d2e #ffd2a0 #ff3d8b`, player fire `#ffd36b #fff3c4`.
- **Player ships**: cream canvas gasbags with ribs/stitching, brass gondolas, oxblood/navy
  trim, spinning propellers, portholes. **Syndicate**: gunmetal hulls, crimson trim, sooty

- Outline everything with a 1–1.5 u dark stroke (`#1a120a` at ~60%) for readability.

- UI: parchment panels, brass frames with rivets, engraved headings, gauges with needles.

## 6. Audio direction
Brass band + accordion + music box + pipe organ + anvil/clank percussion + ship's bell + steam
whistle. Synthesis: brass = sawtooth through enveloped low-pass; accordion = detuned saw/square
pair with tremolo; music box = sine + inharmonic partial, fast decay; organ = additive sines;
kick = pitched-down sine; snare = noise + tone; anvil = FM metallic partials. Cannons = low sine
thump + filtered noise burst + short metallic ring. Explosions = layered noise with lowpass sweep
+ sub thump. Everything mixed through a gentle compressor; nothing harsh or clipping.

## 7. Juice checklist
Muzzle flash + recoil kick on turret, shell smoke; hit sparks + white flash on enemies;
crits bigger, gold numbers; enemy death: explosion + debris + cogs + shake ∝ size; hit-stop
40–80 ms on big kills, 120 ms+ on player hit; trauma-based shake (settings scale); zoom punch
on boss intro/death; slow-mo on boss death & player death; camera leads toward aim; smoke from
damaged ships; propellers spin with speed; level-up radial burst; pickup sparkle trails.

## 8. Accessibility & settings
Volumes, shake scale (0–1.5), reduced flashing (caps flash alpha, no lightning strobe), damage
numbers toggle, auto-fire, aim assist (touch: soft snap to nearest enemy within 20°), FPS meter,
left-handed touch layout, touch opacity, haptics, quality (`auto` default / `high` / `low`).
Quality tiers live in `js/gfx/quality.js` (high → medium → low: DPR cap 2/1.5/1, particle spawn
×1/0.7/0.45 and pool cap, image smoothing, backdrop detail — merged haze/vignette overlay, no
cloud shadows, half-res ground tiles — weather density, lite music). `auto` starts high; the
governor steps down one tier when smoothed gameplay fps stays < 45 for 4 s and back up after
~10 s > 57 fps (each failed step-up doubles that wait). `high`/`low` pin the tier. Pause on blur/visibility loss. Full keyboard and gamepad menu navigation.

## 9. PWA
`manifest.webmanifest` (name, short_name "Brass&Ballast", start_url `./`, scope `./`, display
`fullscreen` + `display_override`, orientation `landscape`, theme `#2b1d10`, background
`#1b130b`, icons 192/512 any + 512 maskable, categories games). `sw.js` precaches every file in
`precache-manifest.js` (generated, versioned hash) → cache-first, stale caches deleted on
activate, navigation falls back to `index.html`. Update flow: new SW waits; page shows "New
rigging available — reload" toast; clicking posts `SKIP_WAITING`. SW is **not** registered on
`localhost`/`127.0.0.1` unless `?sw=1`, and never with `?nosw=1`.

- Lint: `cd brass-ballast && eslint js` (global ESLint 10, flat config `eslint.config.mjs`).
  Zero **errors** in your files is required (`no-undef` catches cross-module slips).
- Smoke harness (headless Chromium via global Playwright):
  ```
  node brass-ballast/tests/smoke.cjs [--page index.html] [--query "autostart=1&autopilot=1&debug=1"]
     [--seconds 15] [--shots <dir>] [--shot-every 5] [--eval "<js>"]... [--eval-at <s>:<js>]...
     [--viewport 1280x720] [--mobile] [--click-start]
  ```
  Prints JSON: console errors/warnings, page errors, failed requests, `BB.debug.report()` if
  present, screenshot paths. Exit 1 on page errors. Each run uses its own free port.
- **URL flags** (WP1 implements in `debug.js`): `debug=1` (exposes `window.BB`), `autostart=1`
  (skip menus, start a run), `autopilot=1` (bot plays), `mode=`, `hull=`, `weapon=`, `stage=N`
  (1-based), `wave=N`, `boss=<id>` (spawn boss immediately), `seed=N`, `god=1`, `mute=1`,
  `level=N` (pre-level with random cards), `aux=a,b` & `passives=a,b` (give these),
  `speed=N` (time scale), `nosw=1`, `sw=1`.
- `window.BB` (debug): `{game, world, Sprites, audio, events, Save, debug:{spawn(type, n, opts),
  boss(id), stage(n), wave(n), god(on), give(cardIdOrUpgradeId), level(n), killAll(), win(),
  lose(), timeScale(s), report()}}`. `report()` returns `{state, fps, enemies, pBullets,
  eBullets, particles, run:{…}, player:{hp, x, y, aux, passives}}`.
- Preview pages: `tests/preview/sprites.html?filter=<prefix>&scale=<n>&bg=<css color>` renders
  every registered sprite in a labelled grid (art & content WPs use it). Add your own preview
  pages under `tests/preview/` named after your WP.
