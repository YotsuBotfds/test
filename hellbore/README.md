# HELLBORE: Tunnel Boring to Hell

A twin-stick shooter where you pilot a tracked dig-tank straight down through six strata of the
underworld, with the tunnel caving in behind you. It's an installable, offline-capable PWA with
no dependencies and no build step. Every asset is generated in code: the pixel font, the tile
textures, the sprites, the lighting, the icons, and all the sound and music, which is
synthesized live with WebAudio.

## Play locally

Serve this folder over HTTP (service workers and ES modules don't load from `file://`):

```bash
cd hellbore
npx http-server -p 8080 -c-1 .
# open http://localhost:8080
```

To install it, open the page in Chrome, Edge, or Android, then use **Install app** in the browser
menu (or the **INSTALL APP** item on the title screen when the browser offers it). On iOS Safari,
use Share → Add to Home Screen. After the first load it works offline.

## Controls

| | Keyboard + mouse | Gamepad | Touch |
|---|---|---|---|
| Move | WASD | Left stick / D-pad | Left thumb, anywhere |
| Aim + fire | Mouse + hold left click, or arrow keys | Right stick (RT fires too) | Right thumb, anywhere |
| Dash (brief invulnerability) | Space / Shift | A / RB | DASH button |
| Throw charge (clears bullets, blasts rock) | Right click / E / Q | B / X / LB | BOMB button |
| Pause | Esc / P | Start | II button |

## The descent

| # | Stratum | Hazard | Warden |
|---|---|---|---|
| 1 | The Crust | mud (slows you) | **Mother Wyrm**: a burrowing segmented worm |
| 2 | The Deep Stone | cold water (slows you) | **The Colossus**: fist slams, boulders, rock rain, crystal beams |
| 3 | Magma Veins | lava (burns) | **Magmaw**: surfaces from lava pools to spiral fire and spit magma |
| 4 | The Ossuary | ectoplasm (burns) | **The Ossuarch**: a skull king behind a ring of regrowing bone shields |
| 5 | Brimstone Gate | lava (burns) | **The Gatekeeper**: hellfire breath, hand slams, walls of fire |
| 6 | The Pit | blood pools (burn) | **The Abyssal Heart**: every heartbeat is a ring of bullets |

After the Heart, the descent loops forever, and each loop makes the strata and wardens harder.

- **Digging:** drive into rock to drill through it. Soft dirt goes fast and dark stone takes time. Shots chip rock, and charges blow out craters. Yellow-green gas pockets explode and set off their neighbours, so you can use them against packs.
- **The cave-in:** the tunnel collapses behind you and speeds up if you fall too far ahead. Keep moving.
- **15 creatures:** grubs, beetles, bats, wall spitters, cave crawlers, golems, magma slimes that split, salamanders, ghouls, phasing wraiths, teleporting imps, hellhounds, laser-eyed watchers, and tunnelling brutes. Most of them claw through rock to reach you.
- **7 weapons**, each upgradable to level 5: Riveter, Scrap Cannon, Plasma Torch, Arc Coil, Rail Driver, Hellfire Pod, and Buzzsaw. Pick up the same weapon again to level it.
- **Powers:** Overdrive, Aegis, Drill Frenzy, and Magneto, found in supply crates.
- **The Forge:** after each warden, spend ore on repairs, nine permanent upgrades, and weapon tune-ups. From the second warden on, the Forge also offers **pacts**, which give big boons with a catch.
- **4 rigs:** Mole, Grinder, Wasp, and Hellion. Slaying wardens unlocks the extra rigs.
- **Daily Dig:** one seeded map per day, the same for everyone, with its own best score.

## Code map

```
index.html            page shell + canvas
manifest.webmanifest  PWA manifest
sw.js                 offline cache (bump VERSION when shipping changes)
icons/                generated by tools/make-icons.mjs (needs `playwright`)
src/main.js           boot, resize, main loop, screen flow, saving
src/game.js           one run: update, lighting, cave-in, spawning, boss flow, rendering
src/world.js          chunked tile world, generation, collision, flow-field pathing
src/player.js         the borer
src/enemies.js        creature behaviours + procedural sprites
src/bosses.js         the six wardens
src/combat.js         weapons, projectiles, pickups, beams/telegraphs/shockwaves
src/gfx.js            procedural tile textures, light stamps, glow sprites
src/font.js           hand-drawn 5x7 bitmap font + logo renderer
src/audio.js          WebAudio sfx, drill/rumble loops, procedural music sequencer
src/input.js          keyboard/mouse, gamepad (with rumble), dual touch sticks
src/hud.js            HUD + touch controls
src/screens.js        title, rig bay, forge, pause, game over, victory, settings, records, help
src/data.js           strata, rigs, weapons, enemies, upgrades, pacts
src/save.js           localStorage settings/records/unlocks
```
